# Smart-Quiz

Smart-Quiz RSSchool Final Project Auto Team 7

## What is it

Smart Quiz is a web application that allows users to test their knowledge of HTML, CSS, and JavaScript across different difficulty levels (easy, medium, hard).

Users can customize quizzes by selecting topic, difficulty, and mode.

The app provides two modes:

- **Train mode** — allows free navigation between questions and saving progress until the quiz is finished.
- **Exam mode** — restricts navigation and requires answering each question before proceeding.

User progress and attempt history are stored in localStorage.

## Environment variables

Currently, the project does not require environment variables to run.

However, for future improvements (Quiz API and AI integrations), `.env.example` is provided.
Environment variables in Vite must start with `VITE_`

To use it:

Copy `.env.example` to `.env` and update values if needed.

Example:

macOS/Linux:
`cp .env.example .env`

Windows:
`copy .env.example .env`
