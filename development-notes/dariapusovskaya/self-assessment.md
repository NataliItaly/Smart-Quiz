Что было реализовано:

Архитектура страницы login-page:

Создана модульная структура страницы логина с разделением на компоненты
Реализовано переключение между формами входа и регистрации без перезагрузки страницы
Настроена маршрутизация с защищёнными маршрутами (доступ к дашборду, квизу и статистике только после авторизации)
Компоненты:

LoginForm.ts — форма входа с полями email и пароль
RegisterForm.ts — форма регистрации с полями имя, email и пароль
index.ts — главный файл страницы, управляющий состоянием и переключением форм
types.ts — централизованное хранение TypeScript интерфейсов для безопасности типов
Функциональность:

Сохранение данных пользователя в localStorage (без бэкенда)
Автоматическое создание хранилища для результатов каждого пользователя
Проверка авторизации при загрузке приложения
Валидация полей форм (минимальная длина пароля, обязательные поля)
Кастомные popup-уведомления вместо стандартных alert
Безопасность:

Защищённые маршруты через auth guard в роутере
Хранение состояния авторизации с возможностью восстановления после перезагрузки
Очистка данных при выходе из системы
